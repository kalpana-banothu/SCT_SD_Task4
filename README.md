# SCT_SD_Task4 - E-Commerce Product Scraper

## Description

This project is a web scraper that extracts product information from an
online e-commerce website and stores the collected data in a structured
CSV file.

## Technologies Used

- JavaScript
- Node.js
- Axios
- Cheerio
- CSV

## Features

- Extracts product names
- Extracts product prices
- Extracts product ratings
- Extracts product URLs
- Scrapes multiple pages
- Stores the extracted information in `products.csv`
